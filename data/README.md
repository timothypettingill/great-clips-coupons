# `./data` directory

## Files

`coupon_urls.txt`

- This file contains Great Clips coupon URLs extracted from active Meta ads. It is generated by the `./scripts/fetch_coupon_urls.py` script.

`coupon_data.json`

- This file contains an array of JSON objects containing data scraped from Great Clips coupon web pages. It is generated by the `./scripts/fetch_coupon_data.py` script.
